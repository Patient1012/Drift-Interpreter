## About
G-Sharp is a personal vibe coded programing language. It takes inspiration from C and C#. The first interpreter is written in C# but I plan to make a compiler written in C in the future.
The first interpreter has been mostly written with ChatGPT but has been extensive modified along the way as I get better at programming. G-Sharp is a personal project which is what I would
like in language regarding syntax. It is not designed to be the best and have the most efficient interpreter but is just a passion project.
